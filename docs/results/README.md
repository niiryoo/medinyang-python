# 측정 원자료

파일명 접두어가 측정 시점과 골든셋 크기를 나타낸다. 섞어 비교하면 대응 질의가 어긋난다.

| 접두어 | 골든셋 | 내용 |
|---|---|---|
| `eval-*` | 110건 | 초기 실행. `per_query` 없음 |
| `pq-*` | 110건 | `per_query` 포함. 이후 220건으로 대체됨 |
| `g220-*` | 220건 | 현행 기준. 대응표본 비교는 이 계열끼리만 |
| `rerank-*` | 220건 | Colab GPU 재순위화. 질의별 20개 점수 포함 |
| `cite-*` | 44건 | 생성 단계. 인용 규칙 A/B |

110건과 220건은 `SEED=42`로 같지만 `PER_INTENTION`이 달라 표본이 겹치지 않는다
(교집합 10건). `scripts/compare.py`는 `source` 기준으로 대응시키므로 계열을 섞으면
대응 질의가 10건으로 줄어든다.

주요 실험 대응은 [../EVALUATION.md](../EVALUATION.md) 참조.
