# ADR-004: 재순위화 점수 기반 폴백 게이팅 — 설계 후 측정으로 기각

## 관측

`BgeReranker.rerank()`가 CrossEncoder 점수를 `_`로 버리고 문서만 반환했다.

```python
ranked = sorted(zip(docs, scores), key=lambda x: x[1], reverse=True)
return [doc for doc, _ in ranked[:self.top_n]]
```

논문 4.2절은 *"관련성 점수가 임계치 미만임을 감지"*하여 폴백한다고 서술하지만,
점수가 함수 밖으로 나오지 않으므로 **구조적으로 불가능한 상태**였다.

실제 폴백 판정은 생성된 답변에 `FALLBACK_KEYWORDS` 문자열이 있는지로 이뤄졌다.

## 원인

폴백 판정의 **근거를 검색 단계가 아니라 생성 단계에 뒀다.** 그 결과
"문서가 질의와 관련 있는가"라는 검색 문제를 "LLM이 모른다고 말했는가"라는
문자열 문제로 바꿔 풀고 있었다.

## 고려한 대안

| 안 | 장점 | 단점 |
|---|---|---|
| (a) 절대 임계값 `score > τ` | 단순 | τ를 정할 근거가 없음 |
| (b) 상대 임계값 (top1과 top2/top5의 gap) | 스케일 무관 | 전부 무관한 경우를 못 잡음 |
| (c) **골든셋 점수 분포에서 τ 결정** | 근거 있는 값 | 골든셋 필요, 과적합 위험 |
| (d) 현행 유지 (LLM 자기보고) | 비용 0 | 생성 후 판정 → LLM 호출 2회, 모델 말투에 판정이 종속 |

작업 착수 시점에는 **(c)를 선택했다.** 골든셋만 확보하면 근거 있는 τ가 나올 것으로 봤다.

## 결정

**(c)를 실행한 결과 기각.** 점수 게이팅을 도입하지 않는다.
`RELEVANCE_THRESHOLD = None`으로 두고, 이것이 누락이 아니라 측정에 근거한 비활성임을
config 주석에 명시했다.

점수 반환 자체는 유지한다 (아래 2차 효과 참조).

## 왜 기각했는가

골든셋 220건에서 top1 점수 분포를 정답/오답으로 나눠 봤다.

```
top1 점수 정답  n=153  중앙값 0.998  범위 [0.000, 1.000]
top1 점수 오답  n=67   중앙값 0.993  범위 [0.001, 1.000]

오답 중 정답 최저점 이상 비율 100.0%
```

두 분포가 사실상 완전히 겹친다. τ를 어디에 두든 정밀도가 기저율(69.5%)에서
0.75를 못 넘고, F1은 **τ=0에서 최대**가 된다 — "폴백을 아예 하지 마라"는 뜻이다.

대안 신호 9종을 AUC로 훑었다.

| 신호 | AUC (base) | AUC (ko) |
|---|---|---|
| top1 | 0.586 | 0.629 |
| top1 − top2 | 0.350 | 0.508 |
| mean top5 | 0.616 | 0.620 |
| std top20 | 0.488 | 0.692 |
| 0.9 초과 개수 | 0.618 | 0.598 |

최고가 0.692다. 0.5가 무작위임을 감안하면 쓸 수 없다.

### 시그모이드 포화가 원인이 아닌 이유

점수가 0과 1에 몰려 있어 `sentence-transformers`의 시그모이드 적용을 의심할 수 있다.
그러나 **시그모이드는 단조함수이므로 임계값 분류 성능(AUC)을 바꾸지 않는다.**
로짓으로 다시 뽑아도 같은 결과가 나온다. 신호 자체가 분리를 못 한다.

### 실제 원인

리랭커는 "이 문서가 이 질의와 관련 있는가"를 본다. 그런데 후보 20건은
**이미 질환이 91~93% 맞는 의료 문서들**이다. 리랭커 입장에서 전부 관련 있다.
실패는 의도 불일치에서 나는데, 그건 리랭커가 보는 축이 아니다.

즉 이 파이프라인의 실패 모드와 리랭커의 판단 축이 어긋나 있다.

## 트레이드오프

게이팅 없이 남겨두면 **근거가 약한 문서로도 답변을 생성한다.** 의료 도메인에서
바람직하지 않다. 다만 대안이 "근거 없는 임의의 τ"라면 그쪽이 더 나쁘다 —
동작하는 것처럼 보이지만 실제로는 무작위에 가까운 게이트가 된다.

키워드 판정은 남겨두되 `"없습니다"`를 제거했다 (ADR-005).

## 2차 효과

기각했지만 **점수 반환은 유지한다.** 점수가 함수 밖으로 나온 덕분에 세 가지가 열렸다.

1. 이 분석 자체 (τ 산출 시도)
2. 재순위화 효과 측정 (ADR-003)
3. 운영 로깅 — 어떤 질의에서 점수가 낮았는지 추적 가능

한 줄 수정이 세 가지를 풀었고, 그중 하나가 실패했다고 나머지를 되돌릴 이유는 없다.

그리고 이 실패가 **개선 방향을 바꿨다.** 검색 점수로 답변 가능 여부를 판별할 수 없다면,
판별 대상을 바꿔야 한다. 질의의 의도를 직접 분류하는 쪽이다 (ADR-006).
