# ADR-006: 질의 의도 분류기 + 메타데이터 필터

**상태: 제안** — 설계만 확정, 미구현.

## 관측

세 번의 실험이 같은 곳에서 멈췄다.

| 축 | E1 ada-002 | E4 최종 | 변화 |
|---|---|---|---|
| 질환 일치@5 | 0.8527 | 0.9336 | +8.09%p (유의) |
| 의도 일치@5 | 0.5555 | 0.5982 | +4.27%p (경계) |

임베딩 교체(ADR-001), 하이브리드(ADR-002), 재순위화(ADR-003) 중
**의도 일치율을 유의하게 올린 것이 하나도 없다.**

두 축을 곱해보면 구조가 드러난다.

```
질환 0.9336 × 의도 0.5982 = 0.5585      실측 Precision@5 = 0.5564
```

거의 정확히 일치한다. **두 오차가 독립적으로 곱해지고 있다.** 의도를 완전히 맞히면
Precision@5의 상한이 질환 일치율인 **0.93 부근까지** 열린다.
재순위화가 벌어준 +3.00%p와는 자릿수가 다르다.

## 원인

의도 라벨이 **문서 본문 앞머리에 문자열로 녹아 있을 뿐**, 질의의 의도와 문서의 의도를
대조하는 장치가 파이프라인 어디에도 없다.

검색기는 "예방법이 뭐야?"와 "치료법이 뭐야?"를 벡터 공간에서 가깝게 놓는다.
둘 다 같은 질환에 대한 짧은 의문문이고, 의미적으로 실제로 가깝기 때문이다.
**임베딩 품질이 좋아질수록 이 문제는 오히려 악화될 수 있다.**

즉 이것은 검색기 성능 문제가 아니라 **표현 설계 문제**다.

## 고려한 대안

| 안 | 장점 | 단점 |
|---|---|---|
| (a) 의도를 본문에서 더 강조 (반복, 앞으로 이동) | 인덱스만 다시 빌드 | 이미 앞머리에 있음. 세 실험이 실패한 축을 같은 방식으로 또 미는 것 |
| (b) 의도별로 인덱스 분리 | 필터가 자동 | 인덱스 11개, 운영 복잡. 의도 오분류 시 복구 불가 |
| (c) **질의 의도 분류 → 메타데이터 필터** | 오분류해도 필터를 풀면 복구 가능 | 분류기 학습·서빙 필요 |
| (d) 의도별 프롬프트 분기 | 생성 품질 향상 | 검색 자체는 그대로 |

## 결정

(c). 질의를 11개 의도 중 하나로 분류하고, FAISS 검색에 `intention` 메타데이터 필터를 건다.

학습 데이터는 **이미 있다.** 질문 파일 86,352건에 `intention` 라벨이 붙어 있어
별도 라벨링이 필요 없다. 골든셋 220건은 평가에 썼으므로 학습에서 제외한다.

분류기 후보는 두 가지를 비교한다.

1. 임베딩 + 로지스틱 회귀 — 학습 수 분, 서빙 비용 거의 0
2. LLM few-shot 분류 — 학습 불필요, 질의당 API 호출 1회 추가

1번을 먼저 본다. 11클래스 분류에 8만 건이면 충분한 규모이고,
파이프라인에 이미 임베딩 호출이 있어 벡터를 재사용할 수 있다.

## 트레이드오프

**분류기가 틀리면 정답 문서가 검색 대상에서 아예 빠진다.** 현재 구조는 의도가 틀려도
질환이 맞는 문서를 부분적으로라도 가져오지만, 하드 필터를 걸면 그 여지가 사라진다.
실패 모드가 "부정확한 답변"에서 "답변 불가"로 바뀐다.

의료 도메인에서 어느 쪽이 나은지는 자명하지 않다. 완화책 두 가지를 함께 설계한다.

- 분류 신뢰도가 낮으면 필터를 걸지 않고 기존 경로로 검색
- 상위 2개 의도를 모두 허용하는 soft filter

전자는 ADR-004에서 실패한 게이팅과 같은 구조인데, **여기서는 성립할 가능성이 있다.**
리랭커 점수와 달리 분류기 확률은 11클래스 분류라는 명확한 문제에 대해 학습된 값이고,
검증셋으로 캘리브레이션을 직접 확인할 수 있다. 다만 이것도 **측정 후 판단한다** —
ADR-004의 교훈이 그것이다.

## 2차 효과

의도 분류기가 생기면 **폴백 판정의 근거가 하나 더 생긴다.** ADR-004에서
검색 점수로는 답변 가능 여부를 판별할 수 없다고 결론 냈는데, 분류 신뢰도는
다른 축의 신호다. ADR-005에서 남겨둔 폴백 분기 구조에 네 번째 사유로 들어간다.

또한 의도별 프롬프트 분기 (대안 d)가 이 위에서 가능해진다. 분류 결과를
검색 필터와 프롬프트 선택에 동시에 쓸 수 있다.

반대 방향의 위험도 있다. 필터가 걸리면 후보 20건이 모두 같은 의도가 되므로
**재순위화가 볼 수 있는 변별 축이 하나 줄어든다.** ADR-003에서 확인한 +3.00%p 중
질환 축 기여만 남을 가능성이 있다. 의도 필터 도입 후 재순위화 효과를 재측정해야 한다.

## 검증 계획

1. 분류기 정확도를 홀드아웃으로 측정 (11클래스, 클래스별 F1)
2. 골든셋 220건에 필터를 적용해 E4와 대응표본 비교
3. 분류 신뢰도와 정답 여부의 AUC — ADR-004와 같은 방식으로, 성립 여부를 먼저 확인

기대값은 Precision@5 0.5564 → 0.93 부근이지만, 이는 **분류기가 완벽할 때의 상한**이다.
분류 정확도가 0.9라면 0.93 × 0.9 = 0.84 수준이 현실적인 목표다.
