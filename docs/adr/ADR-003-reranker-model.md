# ADR-003: 리랭커 모델 선택 — 한국어 특화 모델 기각

> **사용 여부는 [ADR-007](ADR-007-reranker-removal.md)이 대체한다.** 의도 필터(ADR-006)
> 도입 후 재순위화의 이득이 구분불가로 바뀌어 기본 비활성이 됐다.
> 모델 선택(bge-reranker-base > bge-reranker-v2-m3-ko) 결론은 그대로 유효하다.

## 관측

논문과 코드가 쓰는 `BAAI/bge-reranker-base`는 다국어 모델이다. 한국어 의료 질의에
한국어 특화 모델이 더 맞을 것이라는 가설이 자연스럽게 나온다.

동시에, 재순위화가 실제로 효과가 있는지 자체가 한 번도 측정된 적이 없다.

## 원인

리랭커 선택이 "예제에서 본 모델"로 정해졌고 대안과 비교된 적이 없다.

## 고려한 대안

| 안 | 장점 | 단점 |
|---|---|---|
| (a) 재순위화 제거 | 지연 감소 | 효과를 모르는 채 버리는 것 |
| (b) **bge-reranker-base 유지** | 논문 재현, 경량 | 다국어 모델 |
| (c) dragonkue/bge-reranker-v2-m3-ko | 한국어 특화 | 모델 크기 2배 |
| (d) 상용 API (Cohere Rerank 등) | 성능 | 종속성, 비용, 의료 데이터 외부 전송 |

## 결정

(b) 유지. (c)는 측정 후 기각.

(d)는 검토 단계에서 제외했다. 의료 상담 질의를 외부 API로 보내는 것은
성능과 무관하게 이 도메인에서 감수할 사안이 아니다.

## 검증

### 재순위화 효과 (E4 vs E2)

| 지표 | 차이 | 95% CI | 판정 |
|---|---|---|---|
| Precision@5 | +3.00%p | [+0.28, +5.72] | 유의 |
| Precision@10 | +2.59%p | [+0.99, +4.19] | 유의 |
| 의도 일치@5 | +1.36%p | [-1.39, +4.12] | 구분불가 |
| 질환 일치@5 | +2.45%p | [+0.94, +3.97] | 유의 |

효과는 있으나 CI 하한이 +0.28로 0에 근접한다. 그리고 **개선이 질환 축에서 나왔고
의도 축은 구분불가다.** 재순위화도 의도 문제를 풀지 못한다.

### 한국어 특화 모델 (E5 vs E4)

| | Precision@5 | 의도@5 | 질환@5 | MRR | 소요 |
|---|---|---|---|---|---|
| bge-reranker-base | 0.5564 | 0.5982 | 0.9336 | 0.6353 | 97.4s |
| bge-reranker-v2-m3-ko | 0.5600 | 0.5982 | 0.9400 | 0.6319 | 340.5s |

**9개 지표 전부 `구분불가`.** Precision@5 차이 +0.36%p, CI [-1.54, +2.27], MDE 2.72%p.
소요 시간은 3.5배.

MRR은 오히려 ko가 낮다(0.6319 vs 0.6353). 방향이 지표마다 엇갈린다는 것 자체가
차이가 노이즈임을 시사한다.

## 트레이드오프

`구분불가`는 **"차이가 없다"가 아니라 "220건으로는 2.72%p 미만을 판별할 수 없다"**는 뜻이다.
ko 모델에 2%p 정도의 실제 이득이 있는데 못 본 것일 수 있다.

다만 결론은 표본 크기와 무관하게 성립한다. **2.72%p 미만의 불확실한 이득을 위해
지연 3.5배를 지불할 이유가 없다.** 골든셋을 409건으로 늘리면 2%p를 판별할 수 있으므로,
비용 구조가 달라지면 재측정할 여지는 남겨둔다.

또 하나 — 이 측정은 GPU(T4) 기준이다. **CPU 서빙 환경이라면 격차가 훨씬 벌어진다.**
로컬 CPU에서 질의당 25.16초가 걸렸고, 모델이 2배 커지면 그만큼 더 나빠진다.

## 2차 효과

"최신 모델", "한국어 특화"라는 수식어가 곧 성능이 아니라는 것을 이 프로젝트의
데이터로 확인했다. 모델 선택을 카탈로그가 아니라 측정으로 하게 됐다.

그리고 재순위화의 이득이 +3.00%p에 불과하다는 사실이 **개선 우선순위를 바꿨다.**
의도 축이 0.60에 묶여 있고 질환 축은 0.93이므로, 남은 여지는 재순위화 튜닝이 아니라
의도 처리에 있다 (ADR-006).
